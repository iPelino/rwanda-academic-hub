# Afretec Web Development Short Course
## AI-Powered Full-Stack Web Development — Complete Course Guide

> **Who this is for:** Complete beginners and intermediate learners who want to build and deploy a real web application using AI tools — from idea to live product on the internet.
>
> **What you will build:** A fully functional, database-backed web application with a real backend (Supabase), deployed live on the internet (Netlify) — all developed primarily using AI assistance.
>
> **Time commitment:** Approximately 3–5 days of guided work, depending on your pace.

---

## What Makes This Course Different

Most web development courses teach you to write every line of code by hand. This course teaches you something more relevant to modern professional work: **how to collaborate effectively with AI** to build real software.

You will still understand *what* the code does and *why* decisions are made. But instead of memorizing syntax, you will learn:

- How to communicate precisely with AI tools to get professional-quality output
- How to review, test, and iterate on AI-generated code
- How to wire together a real technology stack (frontend + backend + deployment) using AI as your co-developer

This is how a growing number of professional developers actually work today.

---

## The Technology Stack You Will Learn

| Layer | Tool | What It Does |
|-------|------|-------------|
| **UI Design** | Google Stitch | Generate app screen designs from text descriptions |
| **Frontend** | HTML, CSS (Tailwind), JavaScript | The pages users see and interact with |
| **Code Editor** | Antigravity or VS Code | Where you write and edit your code |
| **Version Control** | Git + GitHub | Save your work and collaborate safely |
| **Backend / Database** | Supabase | Store user data, authenticate users, manage data |
| **MCP Servers** | Supabase MCP, Netlify MCP | Connect your AI editor directly to your backend and deployment |
| **Deployment** | Netlify | Put your app live on the internet |
| **AI Assistant** | Claude (Anthropic) / Copilot | Your AI co-developer throughout the entire process |

## How to Use These Guides

Each guide is a standalone document you can follow in order. They are written so that even if you have never built a web application before, you can follow every step.

**Each guide includes:**
- A "Why this phase matters" section — so you always understand the purpose before the steps
- Step-by-step instructions with exact commands and prompts to use
- Real examples from the Rwanda Academic Hub project built during this course
- Common mistakes and how to avoid them
- A checklist at the end so you know when you're ready to move on

**The Rwanda Academic Hub example:** Throughout these guides you will see references to a real project called "Rwanda Academic Hub" — a cross-university event discovery platform built during this course. Use it as your reference point. You will build your own different project, but the process is identical.

## Before You Start — Things You Will Need

Before beginning Phase 1, make sure you have the following:

- [ ] A computer (Windows, Mac, or Linux)
- [ ] An internet connection
- [ ] A Google account (for Google Stitch and Google AI Studio)
- [ ] A GitHub account — you will create one in Phase 5 if you don't have one
- [ ] A Supabase account — you will create one in Phase 7 if you don't have one
- [ ] A Netlify account — you will create one in Phase 9 if you don't have one

That's it. No prior coding experience required.
