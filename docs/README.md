# Rwanda Academic Hub

Rwanda Academic Hub is a concept package for a shared university event discovery platform focused on Rwanda, with a strong Kigali starting point.

The product solves a visibility problem: academic events often stay inside individual university channels, clubs, WhatsApp groups, or internal mailing lists. This platform creates a shared discovery layer so a student, staff member, lecturer, researcher, club leader, or community member from one institution can discover relevant events hosted by another.

This folder contains the product definition for the proposed event management system:

- `CONCEPTS-AND-FEATURES.md` for the product concept, user needs, and feature inventory
- `RWANDA-ACADEMIC-HUB-PLAN.md` for the staged implementation roadmap and delivery structure

## Product Direction

The platform should support:

- events from universities across Rwanda
- a stronger initial focus on Kigali-based institutions and communities
- academic, professional, social, innovation, and public-interest events
- organizers including universities, faculties, departments, clubs, associations, lecturers, and external communities

## Core Goal

Replace isolated event visibility with a shared discovery hub for the wider academic ecosystem.

Example:

A student or staff member at African Leadership University should be able to discover an event hosted at the University of Rwanda, and vice versa, without depending on insider access to that institution's private communication channels.
