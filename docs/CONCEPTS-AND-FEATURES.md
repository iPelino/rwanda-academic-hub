# Rwanda Academic Hub: Concepts and Features

## Product Concept

Rwanda Academic Hub is a cross-university event discovery and participation platform for Rwanda.

It is designed as a visibility hub, not just a single-campus event board. The platform helps people discover what is happening across universities, especially in Kigali, while still supporting events from all provinces and institutions in Rwanda.

The system should feel like a shared academic public square where universities, student clubs, lecturers, associations, innovation communities, and partner organizations can publish events that matter to the wider academic ecosystem.

## Problem Statement

University events in Rwanda are often distributed in isolated channels:

- internal email lists
- faculty notice boards
- class groups
- WhatsApp communities
- Telegram groups
- institution-specific social media pages

This isolation creates several problems:

- people miss relevant events outside their own university
- organizers reach only their immediate campus audience
- cross-university collaboration remains low
- students and staff cannot easily track academic opportunities in one place
- public-facing educational events have limited visibility

## Core Vision

Create one trusted platform where a user can:

- discover academic and community events across Rwanda
- filter by city, university, topic, format, or audience
- see which events are open to everyone versus institution-specific
- follow favorite universities, clubs, and organizers
- register interest or attendance from a single experience

## Essential Product Concepts

### Shared Visibility Layer

The platform should aggregate event visibility across institutions rather than replacing each institution's internal systems.

### Multi-Organizer Ecosystem

Events should be publishable by different organizer types:

- universities
- schools or faculties
- departments
- clubs
- associations
- lecturers
- student leaders
- verified external communities

### Open vs Restricted Access

Each event should clearly show whether it is:

- open to everyone
- open to the academic community only
- restricted to a specific institution
- invite-only or application-based

### Place-Based Discovery

Users should be able to discover by:

- Kigali
- other cities in Rwanda
- campus
- online
- hybrid format

### Trust and Verification

Because academic credibility matters, organizers should have visible identity markers such as:

- verified university organizer
- verified club
- verified lecturer
- verified partner community

## Core Features

### 1. Event Discovery Feed

Users should see a dynamic feed of upcoming events with:

- event title
- organizer name
- university or affiliated institution
- location
- date and time
- event category
- open-to-who label
- registration status

### 2. Advanced Search and Filters

Users should be able to filter by:

- university
- city
- category
- date
- event format
- organizer type
- audience eligibility
- free vs paid
- online vs physical vs hybrid

### 3. Event Detail Page

Each event should include:

- full description
- banner image
- host information
- venue or online link
- schedule or agenda
- speaker list
- capacity information
- registration instructions
- sharing options
- related events

### 4. Organizer Profiles

Organizer pages should show:

- organizer name
- organizer type
- institution affiliation
- verification status
- upcoming events
- past events
- contact links
- social links

### 5. User Accounts and Personalization

Users should be able to:

- create an account
- select their university or community affiliation
- choose interests
- save events
- follow organizers
- receive tailored recommendations

### 6. Registration and RSVP Flow

The platform should support:

- RSVP or attendance intent
- external registration links
- optional in-platform registration for simple events
- waitlists for full events
- reminders before the event starts

### 7. Event Submission Dashboard

Organizers should be able to:

- create new events
- edit events
- upload banners
- set visibility and audience rules
- define registration method
- save drafts
- publish or unpublish events

### 8. Moderation and Verification

Admins should be able to:

- review organizer verification requests
- moderate inappropriate or misleading listings
- feature important events
- manage categories and campuses
- audit edits and publication history

### 9. Notifications

Users should receive:

- event reminders
- updates for followed organizers
- alerts for saved events
- recommendations based on interests and location

### 10. Calendar and Bookmarking

Users should be able to:

- bookmark events
- add events to Google Calendar or other calendar tools
- view saved events in one place

### 11. Featured Hubs and Collections

The platform should support curated sections such as:

- this week in Kigali
- research and innovation
- student leadership and clubs
- scholarships and careers
- women in STEM
- entrepreneurship and startups

### 12. Analytics for Organizers

Organizers should be able to track:

- page views
- saves
- RSVP counts
- click-through to registration
- attendance check-in if enabled

## Recommended MVP Features

For the first launch, the MVP should prioritize:

- public event browsing
- event search and filters
- event detail pages
- organizer profiles
- simple user accounts
- bookmark and follow features
- organizer event submission
- admin moderation
- Kigali-first collections and university directory

- event recommendations using behavioral signals
- institution dashboards
- multi-language support
- API integrations with university calendars
